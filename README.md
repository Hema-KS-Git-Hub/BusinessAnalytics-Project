# BusinessAnalytics-Project

				                             Healthcare Business Domain

This project aims to provide a comprehensive analysis of patient encounters, procedure costs, and payer coverage to uncover patterns of high-cost healthcare utilization and potential financial risks. The objective is to support informed decision-making for resource allocation, patient care management, and financial planning by leveraging SQL - based data analysis across key healthcare tables such as encounters, patients, procedures, payers, and organizations.
